# 《创世纪 · 触碰的三十种可能》
### The Genesis Touch: 30 Variations of Divine Creation

> 致敬米开朗基罗《创造亚当》（西斯廷礼拜堂天顶壁画，1512）经典构图 —— 当指尖即将相触，世界在此诞生与重构。

---

## 🏛 项目背景

米开朗基罗在梵蒂冈西斯廷礼拜堂天顶所绘的《创造亚当》，以神与人手指几近相触的数厘米空间，定格了人类艺术史上最震撼人心的构图张力。这一经典手势代表着生命火花的传递、启蒙的降临与两极维度的交融。

本项目从**科技与共生、宇宙与探索、艺术与哲学、自然与生态、奇幻与超现实、人间与温情**六大维度，构想并生成了 30 幅全新的“创世纪触碰”变种名画，并构建了一个交互式数字艺术画廊网站。

## 🌟 画廊网站特性

1. **古典壁画与现代数字展厅美学**：融合文艺复兴湿壁画肌理与现代化暗黑/羊皮纸双主题切换。
2. **多维分类与实时检索**：支持按 6 大主题快速筛选，支持中英文标题、关键词全字段瞬时高亮搜索。
3. **沉浸式画作灯箱 (Lightbox)**：支持全屏大图预览、上一张/下一张切换、键盘左右方向键导航与 Esc 快捷退出。
4. **深刻的触碰寓意与哲学释义**：每幅作品不仅有图像，还记录了“触碰的象征意义”与传世名言。
5. **一键原图下载与跨端响应**：完美适配手机、平板与桌面宽屏。

## 🚀 本地运行

无需复杂的环境依赖，纯原生现代前端技术栈实现：

```bash
cd the-creation-variants
# 使用任意静态服务器开启即可
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```
